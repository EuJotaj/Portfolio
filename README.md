# JOTA — Portfólio React

Landing page em React inspirada no [landonorris.com](https://landonorris.com), com identidade visual e conteúdo do portfólio [eujotaj.github.io/Portfolio](https://eujotaj.github.io/Portfolio/).

## Stack

- React 19 + TypeScript
- Vite
- Framer Motion
- CSS Modules

## Como rodar

```bash
npm install
npm run dev
```

Abra [http://localhost:5173](http://localhost:5173).

## Build

```bash
npm run build
npm run preview
```

## Personalização

| Arquivo | Conteúdo |
|---------|----------|
| `src/constants/site.ts` | Nome, role, tagline, stats |
| `src/constants/content.ts` | Projetos, skills, redes sociais |
| `src/constants/experience.ts` | Timeline profissional |
| `src/constants/assets.ts` | Caminhos de imagens e links |
| `public/assets/img/` | Fotos dos projetos e logo |
